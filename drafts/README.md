# drafts/

One folder per post, named `<YYYY-MM>-<slug>`.

```
draft.md          the post, with front matter
sources.md        citations with tier and URL
image-brief.md    hero image spec
hero.jpg|.png     16:9 hero image - generated, or added by a human
```

Folders stay here after publishing — this is the content archive. `draft.md` front matter
carries `status:` (`drafting`, `in-review`, `approved`, `published`) and the live URL once
published.

Committing here is what makes a run's work survive; the session container does not.
